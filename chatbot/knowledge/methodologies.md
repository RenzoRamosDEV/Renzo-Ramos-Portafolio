# Metodologías y Buenas Prácticas de Renzo Ramos

## Arquitectura
- **SOLID Principles** — código mantenible, desacoplado y fácil de testear.
- **Clean Architecture** — separar la lógica de negocio de los detalles técnicos y frameworks.

## Testing
- **TDD** — guiar el diseño del software mediante pruebas antes de escribir la solución.
- **Mockito** — mocks precisos para aislar el comportamiento de las unidades de código.
- **Integration Testing** — validar que módulos y servicios funcionan juntos sin errores.
- **Testcontainers** — pruebas con bases de datos reales en entornos controlados y aislados.

## Proceso
- **Git Flow / Trunk-Based** — gestión de versiones y despliegues continuos sin fricción.
- **Agile (Scrum/Kanban)** — entrega de valor constante mediante iteraciones y mejora continua.
- **Spec-Driven Development (SDD)** — contratos técnicos claros antes de desarrollar.
- **Prompt Engineering** — optimizar la interacción con IAs para maximizar la calidad.
- **Agentic Workflows** — automatizar desarrollo y debugging mediante agentes inteligentes.

## UI
- **Component-Based UI** — interfaces modulares, escalables y reutilizables.
- **Responsive Design** — adaptación perfecta a cualquier dispositivo o resolución.
- **AI-Assisted** — copilotos avanzados para acelerar el flujo y la calidad final.
