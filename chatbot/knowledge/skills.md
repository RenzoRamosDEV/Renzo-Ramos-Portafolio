# Stack Tecnológico de Renzo Ramos

## Backend
| Tecnología       | Uso |
| ---------------- | --- |
| **Java**         | Lenguaje base para aplicaciones empresariales robustas, aplicando principios SOLID y patrones de diseño para garantizar escalabilidad. |
| **Kotlin**       | Desarrollo de servicios modernos, aprovechando su sintaxis concisa para arquitecturas limpias y código legible. |
| **Spring Boot**  | Creación rápida de APIs REST seguras y servicios autocontenidos, gestionando eficientemente la inyección de dependencias. |
| **Spring Modulith** | Estructurar aplicaciones monolíticas mediante módulos lógicos bien definidos, facilitando la evolución hacia microservicios. |
| **MySQL**        | Diseño de bases de datos relacionales, optimización de consultas complejas e integridad referencial. |
| **Docker**       | Entornos replicables que garantizan despliegues consistentes en cualquier infraestructura. |

## Frontend
| Tecnología     | Uso |
| -------------- | --- |
| **HTML**       | Estructura semántica priorizando accesibilidad y SEO desde la base. |
| **CSS**        | Estilo de interfaces, diseños responsive y animaciones que mejoran la experiencia. |
| **JavaScript** | Interactividad compleja y lógica de negocio en el navegador. |
| **React**      | Librería principal para interfaces dinámicas basadas en componentes reutilizables. |

## Inteligencia Artificial
| Herramienta      | Uso |
| ---------------- | --- |
| **Claude Code**  | Compañero de programación para refactorizaciones profundas y optimización de algoritmos. |
| **Copilot CLI**  | Agiliza la escritura de comandos complejos y sugerencias contextuales en terminal. |
| **Claude Design**| Conceptualizar y prototipar interfaces de usuario y layouts modernos. |

## Build & Control de versiones
| Herramienta | Uso |
| ----------- | --- |

| **Maven**   | Gestión estructurada de dependencias y automatización del ciclo de build en Java/Kotlin. |
| **Gradle**  | Builds flexibles y rápidos, optimizando tiempos de compilación. |
| **Git**     | Control de versiones y colaboración mediante ramas y commits claros. |
